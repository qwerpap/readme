## 🛠️ Инструменты и пакеты

### State Management
- [Bloc](https://pub.dev/packages/bloc) - Популярная библиотека для управления состоянием
- [Provider](https://pub.dev/packages/provider) - Простой state management
- [Riverpod](https://pub.dev/packages/riverpod) - Мощный state management
- [GetX](https://pub.dev/packages/get) - Все в одном: routing, state, dependency injection

### UI Компоненты
- [Flutter ScreenUtil](https://pub.dev/packages/flutter_screenutil) - Адаптивный UI
- [Cached Network Image](https://pub.dev/packages/cached_network_image) - Кэширование изображений
- [Shimmer](https://pub.dev/packages/shimmer) - Загрузочные анимации
- [Flutter Staggered Grid View](https://pub.dev/packages/flutter_staggered_grid_view) - Сетки с анимацией

### API и сеть
- [Dio](https://pub.dev/packages/dio) - HTTP клиент
- [Retrofit](https://pub.dev/packages/retrofit) - Type-safe HTTP клиент
- [GraphQL Flutter](https://pub.dev/packages/graphql_flutter) - GraphQL клиент

### Базы данных
- [Hive](https://pub.dev/packages/hive) - Легкая NoSQL база данных
- [Sqflite](https://pub.dev/packages/sqflite) - SQLite для Flutter
- [Firebase Core](https://pub.dev/packages/firebase_core) - Firebase интеграция
